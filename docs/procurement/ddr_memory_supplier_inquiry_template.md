# DDR 存储器方案询价模板

## 一、用途说明

本模板用于向代理/供应商同时询价并比较 DDR4 / DDR5 / LPDDR4 / LPDDR5 四类存储器方案，重点比较以下采购与方案风险维度：

- 成本
- 供货
- 生命周期
- 资料完整性
- 替代料风险
- 方案风险

对外统一说明：目标 FPGA / SoC 平台，具体厂商、平台系列和型号暂不披露。

## 二、对外发送正文

您好，

请协助同时评估 DDR4 / DDR5 / LPDDR4 / LPDDR5 四类存储方案，并按下方 TSV 表格格式反馈可推荐的器件方案、价格、交期、生命周期状态、替代料和资料完整性。

主控为目标 FPGA / SoC 平台，具体厂商、平台系列和型号暂不披露。本次只做存储器器件侧的成本、供货、生命周期和资料完整性评估，最终主控兼容性由我方内部确认。

请优先推荐当前可供货、生命周期风险低、资料完整且有明确替代路径的方案。如存在信息冲突或无法确认的项目，请在表格中明确标注“待确认”或“不确定”，不要留空。

## 三、评估要求

1. DDR4 / DDR5：优先推荐可组成 64bit 总位宽的 x16 或 x8 方案。
2. LPDDR4 / LPDDR5：优先推荐可组成 64bit 总位宽的 x32 package width 方案。
3. LPDDR 必须明确 package width 和 die organization，不要只写 x32。
4. 商业级 / 工业级均可，但需要明确温度等级。
5. 如料号存在 NRND / EOL / LTB 风险，必须提供替代料号。
6. 如 datasheet、官网、代理系统、原厂反馈存在冲突，必须在备注中说明。
7. 如果某项信息无法确认，不要留空，填写“待确认”或“不确定”。

## 五、结论要求

请在表格后补充结论，至少回答以下问题：

1. 四类方案中哪一种综合成本最低？
2. 哪一种当前供货最稳？
3. 哪一种生命周期风险最低？
4. 如果最低成本方案和长期供货方案不是同一种，请说明原因。
5. 如果 DDR4 当前价格高于 DDR5，请明确说明。
6. 如果 LPDDR4 并不比 LPDDR5 便宜，请明确说明。

## 六、冲突处理规则

- 料号状态冲突：以原厂官网 / 原厂 PCN / 原厂代理系统为优先依据。
- 封装或 ball map 冲突：必须要求提供 package drawing 和 ball map。
- 价格冲突：必须按样品、1k、5k 分开，不接受单一口头价格。
- 生命周期冲突：若存在 NRND / EOL / LTB 风险，不能作为唯一推荐。
- 兼容性冲突：由我方内部确认，供应商只需列出器件侧资料和风险点。
